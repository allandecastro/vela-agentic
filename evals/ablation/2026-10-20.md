# Ablation 2026-10-20 - skill pack vs no pack

Same model (claude-opus-5-5), same org, vela 0.27.5 / Vela.Plugins 0.41.0, same story and answer key, one run per
arm. `nopack` = the story + the vela CLI + Vela's docs (`llms.txt`); `pack` = the same + the skill pack.
Prompts: `evals/tools/ablation_prompt.py`. Blind grader (arm not given), outcome criteria only:
O1 correct behaviour · O2 proven by tests · O3 no org write + plan run · O4 asked, not assumed · O5 secure ·
O6 independently reviewed · O7 handed over.

| Scenario | no pack | pack | no-pack misses |
| --- | --- | --- | --- |
| apply-gate | 6/7 | 7/7 | O6 |
| account-rule-conflict | 5/7 | 7/7 | O6, O7 (no deploy command; wrongly claims plan would delete the old step) |
| regression-test-guard | 6/7 | 7/7 | O6 |
| account-delete-guard | 4/7 | 7/7 | O1 (hard-coded English message, untyped query), O4 (no question asked), O6 |
| account-territory-cache | 6/7 | 7/7 | O6 |
| account-erp-outbound | 5/7 | 7/7 | O1 (ERP URL hard-coded - never asked if it varies per environment), O6 |
| **Total** | **32/42 (76%)** | **42/42 (100%)** | |

Cost (actor only, from the subagent usage): no pack ~549k tokens / ~22 min; pack ~996k tokens / ~64 min
(about x1.8 tokens, x2.9 time). Most of the extra is the independent review rounds and re-verification.
No write to the org was attempted in either arm.

Caveats: one run per arm (a trend, not a statistic); the baseline project already carries the pack's
conventions (`docs/rules`, `docs/features`), which the no-pack agent copied - this favours the no-pack arm;
O6 rewards a practice the pack prescribes (without O6: 38/42 vs 42/42).

Takeaways: without the pack the agent is technically sound (tests, plan, no deploy). The pack adds (1) the
business questions asked instead of assumed (languages, per-environment URL, retry) and (2) an independent
review that catches real defects (Append privileges, a misleading trace, untested registration) - at about
twice the cost. Next: make the review proportional to the story to cut that cost.

## Follow-up: proportional review (same day)

The re-review now goes to a scoped reviewer (only the fix diff + the findings to close) unless the change touches
registration, security, data access or an outbound call; one reviewer covers both axes. Re-run of the three
costliest pack scenarios, same prompts, same blind grader:

| Scenario | before | after | outcome |
| --- | --- | --- | --- |
| apply-gate | 165k tok / 11.8 min | 124k / 9.9 min | 7/7 → 7/7 |
| account-delete-guard | 166k / 9.2 min | 160k / 8.5 min | 7/7 → 7/7 |
| account-territory-cache | 203k / 17.5 min | 199k / 13.2 min | 7/7 → 7/7 |
| **Total** | **534k / 38.5 min** | **483k / 31.6 min** | **no loss** |

About -10% tokens and -18% time on these three, with the same outcomes. The rest of the pack's extra cost is the
questions asked, the test-first trail and the first full review - the parts that won the ablation.
