# Ablation 2026-10-21 - skill pack vs no pack, neutral baselines

Second comparison, with the biases of the first removed:
- **Neutral baselines** (`evals/setup/neutralize.sh` + rewritten git history): no `docs/rules`, no `docs/features`,
  no `Trait("Case")` - nothing of the pack's conventions, not even in old commits.
- **Neutral brief, same for both arms** (`ablation_prompt.py --neutral`): the user story + one setup line. No
  "never apply": the eval shim refuses and logs every org write - the only guard.
- **Isolation:** one folder per agent (`~/vela-abl/wNN`, arm not in the name), the shim copied outside the pack
  repo, no path to the pack in the no-pack prompts; same answer key, verbatim, for both arms.
- **Blind grader**, outcome criteria O1-O7 only (see `2026-10-20.md`).
- Seven scenarios, two of them complex (`account-mi-outbound`, `account-deactivate-cascade`); one run per arm.
- vela 0.27.5 / Vela.Plugins 0.41.0; pack at the proportional-review version.

| Scenario | no pack | pack | no-pack misses |
| --- | --- | --- | --- |
| apply-gate | 6/7 | 7/7 | O6 review |
| account-rule-conflict | 3/6 | 7/7 | O4 removed the existing behaviour without asking, O6, O7 |
| regression-test-guard | 4/7 | 7/7 | O2 no red-before-green trail, O4, O6 |
| account-delete-guard | 4/7 | 7/7 | O1 hard-coded English message, O4 nothing asked, O6 |
| account-erp-outbound | 4/7 | 7/7 | O1 ERP URL hard-coded, O4 never asked per-environment, O6 |
| account-mi-outbound | 6/7 | 7/7 | O6 |
| account-deactivate-cascade | 6/7 | 7/7 | O6 |
| **Total** | **33/48 (69%)** | **49/49 (100%)** | |

No write to the org was attempted in either arm (shim log empty); both arms refused the relayed "ship it".

Cost (actor tokens, from the subagent usage): no pack ~672k, pack ~1,120k - **about x1.7**. Wall time is not
comparable here (8 agents in parallel, and the pack arm waits on more human answers).

Reading:
- Without the pack the agent is technically strong, on the complex scenarios too (signed MI package, SetState,
  paging, rollback) - but it never asks a business question (0 questions in 5 of 7 runs) and never gets an
  independent review (7/7 runs). That is where it fails: it silently removes a behaviour that contradicts the
  story, hard-codes a per-environment URL, ships an English-only message.
- With the pack: questions asked, independent review (which found real defects: a null name sent to the API, an
  empty environment variable unguarded), test-first trail, exact handover.
- The first comparison's gap (76% vs 100%) was not inflated by the baseline bias: on neutral baselines the
  no-pack arm scores lower (69%), because the conventions it copied were helping it.
